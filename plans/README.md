## Superseded approaches

- **008 eager-load all preloader frames** is superseded by 013. Live staging emits ten image preloads before the portfolio LCP; smooth animation must be achieved without ten `priority` resources.
- **007 drop homepage LQIP** is refined by 016. Removing all LQIP reduced payload, but active and imminent images need a reliable visual placeholder.
- **005 one LCP priority image** is refined by 017. Only one image should be a document-level preload, but every image in the currently visible two/three-image composition must begin loading promptly.
- **011 cache-busted retry** is superseded by 018 because unique query strings defeat CDN cache reuse.
- **018's no-cache-buster result remains valid, but its bounded recovery intent is incomplete**. Plan 029 reopens only deterministic recovery and expands it to Grid and Archive after plan 028 unifies delivery.
- **020 remains the cheap homepage HTML budget**, while 021 adds unit/browser behavior, explicit fail-closed live checks, and Gallery/Archive route coverage.
- **014 remains the portfolio-view URL policy**. It explicitly excluded Gallery and Archive; plan 028 extends the same canonical approach to those surfaces without changing design.

## Findings considered and rejected

- `text-rendering: optimizeLegibility` on `body` (`app/globals.css`) — micro-cost; not worth a plan.
- Orphan `::view-transition-*` CSS without View Transitions API — cleanup-only; defer unless page-transition work is scoped.
- `PageTransition` exit never running without `AnimatePresence` — pre-existing App Router issue; out of this reliability pass.
- Reverting homepage to `getHighlightsCached()` only — product intent on this branch is full-catalog nav; plan 006 keeps all titles while slimming payloads instead.
- Lowering global photographic quality below 75 — not justified without visual approval; plans preserve perceived quality and remove wasted work instead.
- Making all projects/images eager — increases contention and works against reliability; plans use bounded live-window hydration and adjacent-only low-priority prefetch.
- Reintroducing LQIP for every Gallery/Archive image — measured payload cost is too high; plan 027 permits only a bounded above-fold subset while preserving the same grid.
- Changing crossfade duration/easing, grid stagger, layout, object-fit, or composition — explicitly outside this audit and every new plan.
